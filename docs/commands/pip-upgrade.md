## Purpose

Manage agsekit version updates and version discovery.

## Commands

```bash
agsekit pip-upgrade
agsekit check-new-version [--config <path>]
```

## `pip-upgrade`

1. Checks that `agsekit` is installed through `pip` in the current environment.
2. Reads the current installed version through `pip show agsekit`.
3. Runs `pip install agsekit --upgrade`.
4. Reads the installed version again and prints the result:
   - if the version changed, reports the old and new versions;
   - if the version did not change, reports that the latest version is already installed.

## `check-new-version`

1. Determines the configured internal state file path (default `~/.config/agsekit/state.yaml`).
2. Queries `pip` for the latest available `agsekit` version.
3. Updates the state file:
   - `current_version` is kept in sync with the running CLI;
   - `last_Version` is set to the latest version discovered through `pip`.
4. Prints whether a newer version is available and includes a link to `changelog.md` when applicable.

The state file is generated by agsekit itself and starts with a warning comment telling users not to edit it by hand.

## Example

```bash
agsekit pip-upgrade
agsekit check-new-version
```
