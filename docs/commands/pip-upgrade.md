## Purpose

Manage agsekit version updates and discover the latest installable versions of configured agents.

## Commands

```bash
agsekit pip-upgrade
agsekit check-new-version [--config <path>]
```

## `pip-upgrade`

1. Checks that `agsekit` is installed through `pip` in the current environment.
2. Reads the current installed version through `pip show agsekit`.
3. Runs `pip install agsekit --upgrade`.
4. Reads the installed version again and prints the result:
   - if the version changed, reports the old and new versions;
   - if the version did not change, reports that the latest version is already installed.

## `check-new-version`

1. Determines the configured internal state file path (default `~/.config/agsekit/state.yaml`).
2. Queries `pip` for the latest available `agsekit` version.
3. Builds a unique set of agent types from the selected config and, for entries not refreshed during the previous 24 hours, queries their package registry or release source. It does not inspect agent versions inside VMs.
4. For `codex-glibc-prebuilt`, resolves the latest release that contains an asset for the current host architecture; the state contains that architecture's version directly rather than a per-architecture mapping.
5. Updates the state file:
   - `current_version` is kept in sync with the running CLI;
   - `last_Version` is set to the latest version discovered through `pip`.
   - `agent_versions.<type>.latest_version` stores the latest installable agent version;
   - `agent_versions.<type>.updated_at` stores the UTC time of the successful refresh.
6. Prints whether a newer agsekit version is available and includes a link to `changelog.md` when applicable.

The periodic checker may still wake at the configured `check_new_version_interval_sec`, but each agent type is queried at most once per 24 hours after a successful refresh. Failed agent lookups do not remove the last successful value. The state file is protected by an inter-process lock and replaced atomically when written.

The state file is generated by agsekit itself and starts with a warning comment telling users not to edit it by hand. `install-agents --upgrade` consumes the cached agent versions without performing registry requests during installation.

## Example

```bash
agsekit pip-upgrade
agsekit check-new-version
```
