# Troubleshooting

Эта страница собирает самые типичные операционные проблемы.

## Пустые примонтированные папки 

* Папки примонтированы
* Но внутри они пусты
* При попытке примонтировать как agsekit, так и multipass говорят "уже всё примонтировано"
* При попытке отмонтировать возникает ошибка sshfs-сервера

`agsekit doctor` умеет обнаруживать и исправлять такие проблемы.

Как правило, достаточно перезапустить демона multipass

## Несколько версий Node.js с агентами

Если разные Node-based агенты были в разное время установлены в разные `nvm`-версии Node.js внутри одной ВМ, `agsekit doctor` умеет собрать их обратно:

* оставляет самую новую Node.js-версию, в которой уже есть агенты;
* удаляет остальные agent-bearing версии Node.js;
* переустанавливает только те настроенные агенты, которые реально были найдены в этой ВМ;
* версии Node.js без агентов не трогает.
