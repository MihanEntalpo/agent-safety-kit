# `update-vm`

Применяет CPU и RAM из конфигурации к одной существующей Multipass ВМ или ко всем настроенным ВМ.

```bash
agsekit update-vm <vm_name>|--all-vms [-f|--force] [--config <path>] [--debug]
```

Остановленная ВМ обновляется напрямую через настройки Multipass `local.<vm>.cpus` и `local.<vm>.memory`. Если ВМ работает, команда показывает процессы настроенных агентов и спрашивает разрешение на остановку; ответ по умолчанию — «нет». С `--force` работающие ВМ останавливаются, обновляются и запускаются без запроса — это подходит для автоматизации.

ВМ в состоянии suspended пропускаются. Сначала разбудите их через `multipass start <vm_name>`. Команда меняет только CPU и RAM; отличия размера диска не изменяются.

См. также: [жизненный цикл VM](vm-lifecycle.md), [up](up.md).
