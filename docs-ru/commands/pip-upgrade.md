## Назначение

Управлять обновлением agsekit и проверкой доступности новой версии.

## Команды

```bash
agsekit pip-upgrade
agsekit check-new-version [--config <path>]
```

## `pip-upgrade`

1. Проверяет, что `agsekit` установлен через `pip` в текущем окружении.
2. Считывает текущую установленную версию через `pip show agsekit`.
3. Выполняет `pip install agsekit --upgrade`.
4. Повторно считывает версию и печатает итог:
   - если версия изменилась, сообщает старую и новую версии;
   - если версия не изменилась, сообщает, что уже установлена последняя версия.

## `check-new-version`

1. Определяет путь к внутреннему state-файлу из конфигурации (по умолчанию `~/.config/agsekit/state.yaml`).
2. Спрашивает у `pip`, какая версия `agsekit` сейчас самая новая.
3. Обновляет state-файл:
   - `current_version` синхронизируется с реально запущенным CLI;
   - `last_Version` записывается как последняя версия, найденная через `pip`.
4. Печатает, доступна ли новая версия, и при необходимости показывает ссылку на `changelog.md`.

State-файл генерируется самим agsekit и начинается с предупреждающего комментария о том, что его не нужно редактировать вручную.

## Пример

```bash
agsekit pip-upgrade
agsekit check-new-version
```
