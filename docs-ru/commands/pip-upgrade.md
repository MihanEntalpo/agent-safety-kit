## Назначение

Управлять обновлением agsekit и узнавать последние устанавливаемые версии настроенных агентов.

## Команды

```bash
agsekit pip-upgrade
agsekit check-new-version [--config <path>]
```

## `pip-upgrade`

1. Проверяет, что `agsekit` установлен через `pip` в текущем окружении.
2. Считывает текущую установленную версию через `pip show agsekit`.
3. Выполняет `pip install agsekit --upgrade`.
4. Повторно считывает версию и печатает итог:
   - если версия изменилась, сообщает старую и новую версии;
   - если версия не изменилась, сообщает, что уже установлена последняя версия.

## `check-new-version`

1. Определяет путь к внутреннему state-файлу из конфигурации (по умолчанию `~/.config/agsekit/state.yaml`).
2. Спрашивает у `pip`, какая версия `agsekit` сейчас самая новая.
3. Собирает уникальный набор типов агентов из выбранного конфига и для записей, которые не обновлялись последние 24 часа, обращается к package registry или источнику релизов. Версии агентов внутри VM не проверяются.
4. Для `codex-glibc-prebuilt` выбирает последний релиз с asset для текущей архитектуры хоста; в state записывается непосредственно версия для этой архитектуры, без вложенного словаря архитектур.
5. Обновляет state-файл:
   - `current_version` синхронизируется с реально запущенным CLI;
   - `last_Version` записывается как последняя версия, найденная через `pip`.
   - `agent_versions.<type>.latest_version` содержит последнюю устанавливаемую версию агента;
   - `agent_versions.<type>.updated_at` содержит UTC-время успешного обновления.
6. Печатает, доступна ли новая версия agsekit, и при необходимости показывает ссылку на `changelog.md`.

Фоновая проверка по-прежнему может просыпаться с интервалом `check_new_version_interval_sec`, но после успешного обновления каждый тип агента опрашивается не чаще одного раза за 24 часа. Ошибка проверки агента не удаляет его последнее успешное значение. State-файл защищён межпроцессной файловой блокировкой и при записи заменяется атомарно.

State-файл генерируется самим agsekit и начинается с предупреждающего комментария о том, что его не нужно редактировать вручную. `install-agents --upgrade` использует сохранённые версии агентов, не обращаясь к registry во время установки.

## Пример

```bash
agsekit pip-upgrade
agsekit check-new-version
```
