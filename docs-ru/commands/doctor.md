## Назначение

Диагностировать известные проблемы установки и runtime и предлагать безопасные исправления.

## Команда

```bash
agsekit doctor [--config <path>] [-y] [--debug]
```

## Текущая область покрытия

Сейчас команда покрывает два исправляемых класса проблем:

- broken/stale mount visibility в Multipass, когда непустая папка хоста выглядит пустой внутри ВМ;
- хаотично разнесённые Node-based агенты по нескольким `nvm`-версиям Node.js в одной ВМ.

## Поведение

- анализирует настроенные mounts;
- проверяет, не выглядит ли непустая хостовая директория пустой внутри VM;
- проверяет `~/.nvm/versions/node/*` внутри запущенных ВМ и ищет в каждой версии Node-based агенты (`codex`, `qwen`, `opencode`, `cline`);
- если агенты обнаружены в нескольких `nvm`-версиях Node.js, предлагает оставить самой новой из них статус `default`, удалить остальные agent-bearing версии и переустановить только те имена агентов из конфига, которые реально были найдены в этой ВМ;
- версии Node.js без найденных агентов не трогает;
- при проблемах с mount может предложить перезапуск daemon Multipass.

## Примеры

Запуск в интерактивном режиме:

```bash
agsekit doctor
```

Запуск и согласие на применение исправлений:

```shell
agsekit doctor -y
```

Запуск с подробной выдачей диагностики:
```shell
agsekit doctor --debug
```
